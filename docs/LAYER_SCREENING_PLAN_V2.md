# DCCF 逐层探针与双概念敏感性选层：实验规划 V2

状态：实验设计稿，尚未实现，也尚未运行。适用范围是第二研究内容（未见越狱攻击类型的双概念融合检测）。
算法约定以 [METHOD.md](METHOD.md) 与 `configs/qwen2_5_7b.json` 为准。本稿取代
[LAYER_SCREENING_PLAN_V1.md](LAYER_SCREENING_PLAN_V1.md) 中基于旧开发数据的数据现状部分，并把阶段二改成与
Sentinel 更接近的“策略 × 层”双表流程。V1 的统计与泄漏控制原则继续有效，不在此重复。

## 1. 要回答的问题

1. 阶段一（逐层探针）：哪些物理层的末 token 表征能区分正常与有害输入，并且这种能力能迁移到越狱输入？
2. 阶段二（双概念敏感性分析）：在候选层里，哪些层对**风险概念**敏感，哪些对**操纵概念**敏感？
   不同越狱策略各自被哪些层分辨？由此选出互补层，交给后续融合。

不回答的问题：融合后整体检测性能、对未见攻击类型的泛化结论、阈值与误报率保证。这些属于后续阶段。

## 2. 与 Sentinel 的对应关系

核对依据：Sentinel §3.3 P1–P4、Algorithm 1、§4 实现细节与 Fig. 4、Fig. 6。

| Sentinel | 内容 | DCCF 本阶段 |
|---|---|---|
| P1 逐层探针 | 每层一个两层 MLP（100 隐藏单元），交叉熵，早停，最多 500 epoch，用 `P_benign` 对 `P_harmful` 训练，按 AUROC 选候选 | 保留。结构和训练设置照搬，候选门槛由 DCCF 自行登记 |
| P2/P3 漂移与 ACI | 原始与扰动提示的逐层余弦距离，汇总成 ACI | 不用。DCCF 用概念读出代替整体漂移量 |
| Algorithm 1 阶段 2 | 对每个候选层，在 M 个扰动策略上计算探针得分，得到行为向量 `B_l ∈ R^M`（Fig. 4 是“策略 × 层”热图） | 改为**两张**表：风险概念表与操纵概念表，横轴是越狱策略，纵轴是候选层 |
| Algorithm 1 阶段 3 | 对行为向量做余弦相似度，贪心剔除与已选层相似度不低于 `τ_corr` 的层 | 改为按分支做覆盖效用贪心（`select_layers`），冗余项由响应相关性惩罚承担；同时保留 Sentinel 式规则作为对照 |
| 阶段 4 | 拼接所选层隐藏状态，训练 MLP 或逻辑回归 | 不在本阶段。DCCF 后续用概念读出加稀疏线性融合 |

需要老实说明的两点：

- Sentinel 的 `τ_acc`、`τ_corr` 在论文里只是符号，没有给出数值。DCCF 的门槛是自己的预注册选择，不是 Sentinel 的报告值。
- Sentinel 的探针标签只有 benign 对 harmful，没有越狱标签。本稿的探针同样如此，越狱输入只用来检验迁移。你给出的描述（“选出能区分越狱攻击的隐藏层”）如果指**直接用越狱标签训练探针**，那是另一种设计，见 §4.4 的备选与它的泄漏风险。

## 3. 数据现状（已核对）

数据：`data/dccf_v1/`，`validate` 通过。标签是两名 LLM 审核加一名 LLM 裁决，不是人工真值。

| 角色 | 记录 | 目标组(H) | B | J |
|---|---:|---:|---:|---:|
| train | 1222 | 279 | 279 | 664 |
| select | 257 | 57 | 57 | 143 |
| confirm | 256 | 57 | 57 | 142 |
| calibrate | 200 | - | 200 | - |

阶段一、阶段二只使用 train 和 select。**confirm 本阶段不碰**，`calibrate` 也不碰。`diagnose` 为空。

### 3.1 “策略”这条轴的实际情况

家族级（6 类）样本量：

| 家族 | train | select | 说明 |
|---|---:|---:|---|
| template（JBV 与 JBB-JBC 模板） | 496 | 103 | 一个家族，内含 30 个模板谱系 |
| persuade | 38 | 11 | |
| saa | 38 | 6 | select 样本很少 |
| dsn | 30 | 11 | |
| gcg | 33 | 7 | select 样本很少 |
| pair_tap | 29 | 5 | select 样本很少 |

三个后果：

1. 6 个家族里 template 占了 74%（train+select 的 807 条 J 中 599 条），直接按家族做横轴会让 template 主导所有汇总。
2. gcg、pair_tap、saa 在 select 只有 5 到 7 个目标组，单格估计极不稳定。
3. 每个模板谱系对应一个“包装策略”，比“template”更接近 Sentinel 的扰动策略。train+select 的 template 家族共 28 个谱系；全部 33 个策略（28 个谱系加 5 个非模板家族）里，样本不少于 20 的有 16 个。

因此横轴采用**两级**：

- 主表（家族级）：6 列，用于和攻击类型叙事对应；
- 细表（谱系级）：样本不少于 20 的 16 个策略（11 个模板谱系加 5 个非模板家族）各占一列，其余 17 个小谱系（合计 123 条）并入“其他”列并标注。

所有格子同时报告 `n_goal_groups` 与区间，分母小于 15 的格子在热图中以斜线标记，不参与排序结论。

### 3.2 已知缺陷（影响本阶段解读）

- 同一目标的 H 与其全部 J 属同一目标组，已在划分中保持同区，但**模板谱系跨区共享**（train 有 27 个、select 有 25 个模板谱系，其中 24 个两边都有）。因此 select 上的结果不能解读为“对未见谱系的泛化”。要回答这一点必须做谱系或家族留出，见 §5.3。
- B 的来源混杂：train+select 的 336 条 B 里只有 14 条是 JBB 官方 benign，其余 322 条是 LLM 撰写（第一轮 178、第二轮 144）。探针可能学到“撰写风格”而不是风险。官方 B 太少，无法做来源分层对照，§4.3 改用别的办法。
- 风险配对（H-B）只在 train 区进入加载器。select 区的 H-B 配对在 `annotation/pairs_risk_all_roles.jsonl` 里，可以用，但不是 `load_dataset` 默认读取的。
- 校准材料与越狱格式不匹配，本阶段不用。

## 4. 阶段一：逐层 MLP 探针与候选池

### 4.1 前置：状态提取

用 `python -m dual_concept extract` 在 train 与 select 上提取一次，缓存绑定协议哈希。提取前先做表征闸门：

- 重核模型 revision、tokenizer 与 chat template 哈希、层号、精度；
- 本地没有 Qwen2.5-7B-Instruct 权重（HF 缓存里只有空目录），需要先下载约 15 GB，或在有 GPU 的服务器上跑；
- 数据 `max_formatted_tokens=546`，远低于 `max_length=2048`，不会触发截断错误。

提取量：train 1222 加 select 257，共 1479 条，每条 27 层 × 3584 维。float16 约 0.3 GB，规模很小，瓶颈只在前向。

### 4.2 探针训练

| 项目 | 设置 | 来源 |
|---|---|---|
| 结构 | `3584 → 100 → ReLU → 2`（或单 logit 加 sigmoid，等价） | Sentinel §4 |
| 损失 | 交叉熵 | Sentinel §4 |
| 早停 | 在训练折内部再划出 15% 目标组作早停集，耐心 20 | DCCF 自定，开发前冻结 |
| 上限 | 500 epoch | Sentinel §4 |
| 优化器 | AdamW，lr 1e-3，weight decay 1e-2，batch 64 | DCCF 自定 |
| 输入标准化 | 仅用当折训练行的均值与标准差，常量维度尺度设 1 | DCCF 自定 |
| 重复 | 5 个种子 × 5 折，折按 `group_id` 划分 | DCCF 自定 |

训练标签：`B=0`，`H=1`，仅来自 train 的 279 个目标组，共 558 条。每个提示只出现一次。**J 不进入探针训练**。

优化器、学习率、早停耐心都在看 select 之前固定。不用 select 调这些超参。

### 4.3 候选准入与诊断

主指标是折外 `AUROC(B vs H)`。登记准入规则：

- 5 折 × 5 种子的 AUROC 中位数不低于 `tau_probe = 0.70`；
- 按折汇总的最差 AUROC 不低于 0.55；
- 不低于 4/5 个种子的折间均值大于 0.5。

这是 DCCF 工作门槛。看到 select 结果后**不得**下调。

提醒：558 条样本里，B 与 H 常常只差几个词，Qwen 中后层上这个任务大概率接近饱和（AUROC 接近 1），门槛 0.70 可能几乎不筛掉任何层。这也是 Sentinel Fig. 3 的现象。如果最终有超过 24 层通过，则 `C_probe` 基本等于全集，阶段一实质上退化。为了不事后改规则，**现在就登记一条补充**：同时报告 `AUROC` 的折间标准差，以及“比最佳层低不超过 0.02”的层集合，作为描述性辅助，不改变准入。

三项必做诊断，用来判断 B/H 探针学到的是风险还是别的：

1. **J 迁移**：把每层探针（折外模型）用在 select 的 J 上，报告每个家族的 `AUROC(B vs J)` 与固定在训练 B 的 5% FPR 阈值上的 TPR。这回答“普通有害信号能否迁移到越狱输入”。
2. **撰写风格对照**：官方 B 只有 14 条，不能分层训练。改为两步：(a) 对 14 条官方 B 单独报告探针的折外得分分布，与同折撰写 B 的分布比较；(b) 用词袋逻辑回归（只看词面）训练同一 B/H 任务，报告其折外 AUROC。若词面基线已很高，说明 B 与 H 的差别主要在词面，探针高分不足以证明学到风险表征。
3. **长度与格式对照**：把字符数、token 数作为单变量基线，报告其 AUROC。若基线已经很高，则 H 与 B 的长度差异在泄漏信号。

### 4.4 备选：直接用越狱标签的探针（扩展，不是主分析）

如果你的意图是“选出能区分越狱攻击的隐藏层”，就需要额外一类探针 `H=0 / J=1`（操纵探针），必须按攻击家族或谱系留出验证，否则同一包装同时出现在训练与筛选里。它产出 `C_manip_probe`，候选集扩展为 `C_probe ∪ C_manip_probe`。这是 DCCF 的新变体，不能叫 Sentinel P1。作为消融保留（§7）。

## 5. 阶段二：双概念敏感性分析

### 5.1 每折先重建概念参数

仅用该折训练目标组构造方向与锚点，沿用 METHOD.md：

- 风险差分 `D^T = h(H) - h(B)`，操纵差分 `D^J = h(J) - h(H)`；
- 每层未中心化秩 1 SVD，得到 `v^T_l`、`v^J_l`，锚点 `μ^b_l`、`μ^h_l`；
- 读出 `c^T_l(x) = cos(h_l(x) - μ^b_l, v^T_l)`，`c^J_l(x) = cos(h_l(x) - μ^h_l, v^J_l)`。

验证折只做冻结读出，不重估方向、锚点或阈值。只在 `C_probe` 的层上计算。

### 5.2 两张“策略 × 层”表

对应 Sentinel Fig. 4 的“策略 × 层”热图，但拆成两张，含义不同，不合并成一个“敏感性分数”。

**表 R（风险概念）**。单元 `(l, m)`：

- `AUROC(B vs J_m)`：风险读出区分正常与策略 m 的越狱输入；
- `TPR(J_m)`：阈值定在该折训练 B 的 5% FPR；
- 同时给出 H 基线列（`AUROC(B vs H)`），用来看越狱输入相对未包装有害输入丢了多少风险信号。

解读：该层风险信号在策略 m 的包装下是否仍然可读。

**表 J（操纵概念）**。单元 `(l, m)`，使用精确匹配的 `(J_{i,m}, H_i)`：

- `AUROC(H vs J_m)`：操纵读出区分包装请求与其对应原始有害目标；
- `TPR(J_m)`：阈值定在该折训练 H 的 5% 误判率；
- 配对差 `Δ^J_{l,m} = mean_i[c^J_l(J_{i,m}) - c^J_l(H_i)]`，附中位数。

解读：该层的操纵方向能否分辨包装，以及对不同策略的敏感度是否不同。H 在这张表里只是参照负类，其“误报”不是安全 FPR。

两表共同要求：

- 长表字段：`branch, layer, strategy_level(family|lineage), strategy, metric, estimate, ci_low, ci_high, n_goal_groups, n_prompts, threshold_source, fold_id`；
- 置信区间用目标组 bootstrap（2000 次），不是按提示重采样；
- 分母小于 15 的格子标记“低样本”，不参与排序；
- 热图固定色标，格内标注 n。

风险表不是因果解读。B 与 J 不在同一目标上，`AUROC(B vs J_m)` 是可分性，不是包装造成的变化量。策略对隐藏状态的配对影响只能从表 J 读。

### 5.3 内部留出与选层

沿用 METHOD.md：对 train 与 select 共有的每个家族建立内部留出折，删除该家族的训练攻击与操纵配对后重建概念，再在 select 的该家族上读表。

因为谱系跨区共享，**仅做家族留出不足以回答“新包装”**。增加一组谱系留出折：对样本不少于 20 的 11 个模板谱系逐个留出，同一谱系的所有 J 及其操纵配对从训练中移除。两套折分别出表，选层以家族折为主、谱系折为稳健性检验。

选层规则：

- 两分支独立，都只能从 `C_probe` 中选；
- 使用现有 `select_layers`：准入 AUROC 取各留出组最差值，门槛 0.55；贪心效用为最差组覆盖增益加 0.25 倍均值覆盖增益，减去新增安全误报与 0.05 倍最大响应相关性；
- 每分支 2 到 4 层，候选不足 2 层则显式失败，不回填；
- 两分支层集可重叠，后续融合取并集，同一物理层的组惩罚按合并后计。

现有代码缺口：`select_layers` 接收的层轴就是候选轴，但没有“探针候选掩码”的传入点。实现时在调用前按 `C_probe` 切片层轴即可，不需要改选层逻辑。

### 5.4 Sentinel 式规则作为对照

对每个候选层，取表 R（或表 J）某一分支中的行向量 `B_l ∈ R^M`（M 为策略数，取家族级 6 列），按探针 AUROC 降序，贪心保留与已选层余弦相似度低于 `τ_corr` 的层。`τ_corr` 取 0.9 与 0.95 两档并同时登记，层数预算与 DCCF 规则一致。这是为了回答“DCCF 的覆盖效用是否比 Sentinel 的相关性去冗余更好”，不是复现 Sentinel。

## 7. 对照与消融（本阶段内完成）

1. 全层对照：不经探针预筛，27 层直接做两分支选层；
2. 探针候选：限定 `C_probe` 后选层；
3. 单层对照：每分支仅取内部验证 AUROC 最佳单层；
4. 单分支对照：仅风险、仅操纵；
5. 互补规则对照：覆盖效用对 Sentinel 式 `τ_corr`；
6. 候选扩展：`C_probe` 对 `C_probe ∪ C_manip_probe`；
7. 探针标签：B/H 对 B/(H+J)（后者训练时见到 J，不可作未见结论）；
8. 随机层：同候选数与同预算随机抽层，重复至少 200 次取分布。

全部使用同一冻结表征、同一文本与折、同一阈值预算。

## 8. 稳定性与停止条件

报告层集合在种子（5）和目标组 bootstrap（200 次）下的出现频率。以下情况按“失败或证据不足”报告，不事后改规则：

- `C_probe` 少于 2 层；
- 任一分支选不出 2 层；
- 某家族的有效配对不足 15 个目标组却被用于排序；
- 层集合在种子间 Jaccard 低于 0.5；
- 词面基线 AUROC 不低于 0.95（此时探针候选的区分力不能归因于风险表征，需在报告中降级结论）。

## 9. 本阶段不能下的结论

- 不能把 select 上的结果称为独立性能。选层与评估共用了 select；
- 不能把 confirm 用于任何调参。confirm 在后续融合冻结后才运行一次；
- 不能声称“对未见攻击类型有效”。要这样主张必须外层留出整个家族，并在外层内重做探针筛层与双概念选层；
- 不能把 LLM 标注当人工真值；
- 不能把层筛选结果说成减少了推理计算，主干前向仍完整执行。

## 10. 执行顺序

1. 取得 Qwen2.5-7B-Instruct 权重并通过表征闸门（revision、模板、层号、精度）；
2. 提取 train 与 select 的状态缓存；
3. 冻结 `config.json`（超参、种子、`tau_probe`、折清单、对照列表）并记录哈希；
4. 阶段一：27 层 × 5 折 × 5 种子探针，产出候选池与三项诊断；
5. 阶段二：在 `C_probe` 上出家族级与谱系级两套双表和热图；
6. 分支选层、对照与消融、稳定性分析；
7. 写 `report.md`，所有数字附样本量与区间，限制写在前面。
