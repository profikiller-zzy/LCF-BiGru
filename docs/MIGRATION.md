## 复现与缓存

`tools/migrate_legacy_data.py` 使用 Python 标准库离线迁移，不依赖旧代码。`--legacy-root` 可指向上述完整备份或其 phase13 子目录；`--output data` 指定新数据目录。脚本在写入前检查来源哈希、JSON、分区和配对端点，输入与输出数据的 SHA-256 保存在 manifest 中。损坏记录或配对冲突会终止迁移。

旧缓存不足以完整提供新主线所需的 **1–27 层候选状态及统一提取协议**，不能据此宣称已完成新网络训练。后续需按新协议重新提取状态，再执行选层、融合训练和安全校准。旧模型分数、旧测试结果与历史增益不作为新实现的实证结果。
