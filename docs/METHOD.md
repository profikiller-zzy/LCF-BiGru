# 双概念互补跨层检测方法

本实现对应期中报告第二研究内容：冻结语言模型，以风险与操纵两类概念的跨层标量响应检测输入风险。最终正类包括原始有害请求和越狱请求。以下说明代码当前行为；配置默认值是可调整的实现选择，尚非实证最优，也不代表已验证双概念融合增益。

## 冻结表征与概念

默认主干为 Qwen2.5-7B-Instruct，候选为物理第 1–27 层，排除输入嵌入和末层归一化状态。每条请求通过模型聊天模板格式化，包含回答起始前缀，取 `attention_mask` 中最后一个有效位置的各层隐藏状态。候选状态默认维度为 3584。超长格式化输入报错，不静默截断；主干参数冻结，不调用 `generate`，不输出回答。

训练区既有风险对按“原始有害减正常”构造差分矩阵，操纵对按“越狱减对应原始有害”构造：

\[
D_l^T[i]=h_l(x_i^h)-h_l(x_i^b),\qquad
D_l^J[i]=h_l(x_i^j)-h_l(x_i^h).
\]

每层分别提取**未中心化**矩阵的第一右奇异向量，得到单位方向 \(v_l^T,v_l^J\)。计算使用 float64 的 Gram 矩阵特征分解，并检查数值残差。方向符号与训练配对差分均值对齐；近零对齐时令绝对值最大坐标为正。全零差分报错。

正常锚点 \(\mu_l^b\) 来自训练区正常记录均值；原始有害锚点 \(\mu_l^h\) 来自有效训练操纵对中去重后的原始有害端点均值。查询只读冻结参数：

\[
c_l^T(x)=\cos(h_l(x)-\mu_l^b,v_l^T),\qquad
c_l^J(x)=\cos(h_l(x)-\mu_l^h,v_l^J).
\]

这是有符号 anchored cosine，零偏移响应为零。查询不重新做 SVD，也不更新锚点或方向。

## 分支任务与内部攻击留出

风险分支 AUROC 的正类为原始有害及当前留出家族越狱，负类为正常。操纵分支正类为当前留出家族越狱，负类为其**精确对应的原始有害**；正常样本仅作为安全误报控制，不加入操纵 AUROC 的负类。原始有害作为操纵负类不意味着它属于安全请求。

对 train 与 select 共有的每个攻击家族建立内部留出折：从训练输入与操纵构建对中去掉该家族攻击，重新构建两个概念方向与锚点，然后在 select 中该家族攻击及相应控制上评估。直接有害任务仍保留为风险监督。GCG 与 nanoGCG 合并为一个家族，PAIR 与 TAP 合并为一个家族。

每折选层操作点只从该折训练参考响应确定：风险分支使用训练正常响应，操纵分支使用训练对应原始有害响应；默认允许参考误报比例为 0.05。这些是选层内部参考阈值，与最终安全校准阈值不同。

## 互补选层

两个分支分别选层。默认先要求候选层在内部折及正类组上的**最差 AUROC 不低于 0.55**，然后按新增漏检覆盖贪心扩展集合。已选集合的覆盖用各层超过冻结参考阈值的并集定义。每次新增层的效用为：

\[
U=\Delta\mathrm{TPR}_{worst}
 +0.25\Delta\mathrm{TPR}_{mean}
 -\Delta\mathrm{FPR}_{safe,macro}
 -0.05\max_{k\in S}|\mathrm{corr}(c_l,c_k)|.
\]

AUROC 用于候选准入和并列时排序，不是上述效用中的额外加项。安全误报增量在实际正常控制上计算，相关性惩罚抑制响应冗余。默认每分支最少 2 层、最多 4 层；达到最小预算后，仅在效用大于 0 时继续增加。候选不足 2 层会报错，不用未达标层补足。各权重、准入阈值和预算均在配置中明确记录。

## 线性融合与最终安全阈值

选层结束后，在外层可用训练区重新构建最终概念参数。按风险特征在前、操纵特征在后拼接 \(z=[c^T;c^J]\)，只用 train 的均值与总体标准差做标准化；常量列尺度设为 1。

融合分数为线性 logit \(s(x)=w^\top\widetilde z+b\)，以正常为 0、原始有害和越狱为 1 训练。目标为平均二元交叉熵加物理层组稀疏惩罚：

\[
\frac1N\sum_i\mathrm{BCE}(y_i,\sigma(s_i))
 +\lambda\sum_l\|w_l\|_2.
\]

同一物理层即使同时进入两个分支，也属于同一个惩罚组；截距不受罚。默认 \(\lambda=0.01\)，近端梯度优化未收敛时禁止冻结模型。

最终只在独立于 train/select 的 140 条正常候选校准 logit 上确定阈值。默认预算为 \(\lfloor140\times0.05\rfloor=7\) 个校准误报；同分时向保守方向处理，使 `s(x) >= τ` 的校准误报数不超过预算。它约束校准样本上的经验比例，不能推出未来数据的误报保证。

train 负责参数拟合，select 负责内部留出与选层，calibrate 只负责最终安全阈值，diagnose 仅供冻结后诊断。指定外层留出攻击家族时，该家族攻击及其操纵对不参与概念拟合、内部选层或融合训练；最终确认数据也不参与任何拟合。直接有害目标仍可保留，因此攻击家族留出不等同于语义目标完全未见。

冻结文件保存层集合、概念参数、标准化、融合权重、logit 阈值及数据和提取协议指纹。当前实现仍执行完整主干前向，没有因选择较浅层或组稀疏而提前退出；只能据此描述检测头结构，不能预先宣称主干计算已减少。
