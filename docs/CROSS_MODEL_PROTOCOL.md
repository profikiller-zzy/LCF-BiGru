# DCCF 跨主干开发实验协议（2026-11-04 冻结）

本轮在用户指定 RTX4090-48G 单卡实例上复现并扩展现有方法。已有材料仍为开发材料，候选标签不改称人工真值，diagnose 不改称独立确认集。不根据本轮 diagnose 表现挑模型、层、超参数、模板或操作点。

## 主干与输入

先运行 Qwen/Qwen2.5-7B-Instruct、Qwen/Qwen2.5-1.5B-Instruct、Qwen/Qwen3-4B、Qwen/Qwen3-8B。Meta Llama-3.2-3B-Instruct、Llama-3.1-8B-Instruct、Meta-Llama-3-8B-Instruct 因当前用户无仓库授权而暂缓；最后一项由用户从基础版更正为 Instruct 版。不借镜像绕过授权。

每模型固定官方 commit、完整权重 SHA256、tokenizer、原生聊天模板、FP16、batch1 与依赖版本。Qwen3 显式 enable_thinking=false；模板附带的空 think 输入前缀保留，只做输入前向，不生成答案。所有实际渲染均通过 render_chat_input。每模型取物理层1至L-1，排除嵌入与最终归一化层，报告物理编号和相对深度。两种Qwen2.5有28层；两种Qwen3有36层。

对同一1665条文本ID逐模型审计完整模板长度，统一提高各模型的max_length以覆盖全部输入；最长请求batch1实测显存、有限值与形状。任一预检失败时保留失败证据，不截断、不删样本、不换精度以追逐diagnose表现。缓存绑定模型、checkpoint、模板kwargs和全部协议；同一模型仅一次完整提取，各模型独立拟合检测头，不宣称概念方向跨模型直接迁移。

## 主实验和诊断操作点

每模型独立运行 full、autodan、drattack、gcg、pair_tap、saa，共24组。遵守METHOD.md中的train/select/安全calibrate边界及内部/外部攻击族留出，方法默认选择惩罚、准入、预算和融合收敛条件不变。

预先报告alpha=.01与.05两个操作点：用每个冻结头的calibrate安全分数分别确定阈值，再在diagnose计数，统一score>=threshold。每个家族正例与该模型共用安全对照计算AUROC，同时保留TP/FN/n和安全FP/n/FPR。安全校准140条时，1%预算仅1个FP，5%预算7个FP；校准经验预算不保证诊断分布的FPR。不得在diagnose上重新选择阈值以凑目标误报。

## 参考模型控制实验

在Qwen2.5-7B的六个冻结baseline上，各做risk_readout_only、manipulation_readout_only、no_group_penalty三项head重拟合，共18项。概念与两个独立选层列表冻结；前两项令被移除读出列的训练值和最终系数严格为0，后一项仅令组稀疏正则为0。标准化与head只用该外部留出过滤后的train，阈值只用calibrate。先完成拟合冻结，再读取diagnose。

这些是选层后的读出贡献控制，不能称为完整单概念重选层，也不验证配对构造本身的因果贡献。不收敛或其他失败不调参重试，不伪造指标；失败项与成功项共同报告。

## 开销

参考Qwen2.5-7B从train/select按完整模板长度分位数选固定最多32条文本ID，其他模型复用同一文本顺序，并重新统计各自token数。固定batch1、2轮暖机、每条3次测量，CUDA阶段同步。分别报告冷加载、主干前向、检测头和端到端的P50/P95与峰值显存；冷加载不清OS缓存，检测头不含缓存I/O。当前实现仍执行完整主干并读取hidden states，选层与稀疏不提供主干提前退出，不能据此宣称主干推理提速。

现有风险训练对200，操纵对train200/select40/diagnose20，原始端点关系齐全。两种配对有害端点的重叠仅34个原始目标、68条训练越狱；完整受控三元组、正常内容加操纵包装控制、独立语义保持核验和新的独立确认材料仍不足。方向几何/不共线只作数值诊断，不等同语义概念分离。跨语言、表达变化与自适应攻击不由本轮换主干自动得到验证，需另建真实材料并预先固定评价。
