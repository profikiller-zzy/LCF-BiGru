## 1. 研究问题与可支持的贡献

研究对象：白盒访问冻结、开放权重、已对齐 LLM 的输入隐藏状态，在生成回答前，检测原始有害执行请求及有害目标的越狱尝试，重点考察未参与该检测头训练的攻击家族。

主假设不是“余弦漂移就是越狱概念”，而是：通过配对构造获得的风险和操纵两种操作性读出，能否在控制包装混杂后，提供跨层互补信息，从而改善未见攻击家族的检出，同时保持可接受的正常误报。

|研究问题|待检验假设|主要证据|
|---|---|---|
|RQ1 概念有效性|风险读出与有害目标有关，操纵读出对操纵包装有额外响应|四格、目标保持审核、等长度扩写、普通角色、安全分析对照|
|RQ2 双概念价值|双概念优于完整重选与训练的单概念|T-only、J-only、完整模型的配对比较；独有检出和漏检重叠|
|RQ3 跨层互补|新增漏检覆盖比单纯 AUROC 排序或去相关更有效|相同预算下的选择器消融、覆盖曲线与最终检出|
|RQ4 未见类型泛化|效果不只来自记忆目标、模板或来源|家族留出；家族与目标双留出；模板/来源扩展验证|
|RQ5 轻量融合|少量标量读出与物理层组稀疏能减少检测头开销|固定特征的正则消融、参数数目、真实延迟与显存|

不预先承诺融合必然提高性能，也不以方向夹角、t-SNE 分簇或低相关性证明因果解耦。双概念、四类数据、多层检测均已有相关工作；贡献应由上述受控验证与泛化结果支持。[WildJailbreak 数据卡](https://huggingface.co/datasets/allenai/wildjailbreak)已包含普通/对抗、有害/正常四种条件；[Revisiting JBShield](https://arxiv.org/abs/2605.03095)已研究多层表示指纹，须纳入相关工作定位。

## 2. 固定任务和标签边界

### 2.1 主检测任务

- 主正类：明确要求执行有害目标的原始请求 H，以及保持该目标的越狱尝试 W(H)。尝试失败或模型拒绝，不改变输入的有害目标标签。
- 主负类：经输入语义审核的正常请求 B、独立普通/困难安全请求，以及预先审核确属安全的对照子集。
- 检测的是输入风险，不以“来源攻击在另一模型上成功”作为当前模型的成功证据。
- 正常目标加真实越权操纵的 W(B)，在本版单独作为操纵诊断组，不强塞进主二分类正负分母。对其中核验安全的子集另报 FPR。扩展到“所有指令越权均为风险”的任务应另立协议，不能中途更改主任务。
- 主干与生成过程均不做干预；检测流程仅输入前向。攻击成功分析可使用独立评估材料/工具，不加入在线检测运行依赖。

### 2.2 多轴标签

|字段|取值/含义|依据|
|---|---|---|
|harmful_goal|0 / 1 / uncertain|完整上下文中被要求执行的目标；不是敏感关键词有无|
|manipulation_intent|0 / 1 / uncertain|是否存在实际的指令覆盖、安全绕过或越权处理企图；普通角色/格式要求不自动为 1|
|primary_label|0 / 1 / null|按本版主任务映射；越权但正常目标的争议组为 null 并单列|
|goal_preserved|yes / no / uncertain / not_applicable|W(H) 是否仍要求原 H 的有害目标，W(B) 是否保留正常目标|
|wrapper_transport|exact / strategy_matched / not_transportable|同一包装可精确迁移、仅同策略匹配，或无法合法构造|
|attack_success|success / failure / unknown / not_evaluated|绑定目标 LLM、生成协议和输出审核；不是输入标签|
|label_status|candidate / human_reviewed_single / human_reviewed_double / adjudicated|实际审核过程，不把候选字段改名成人工真值|
|review_reason|简短理由与证据定位|可核查的标签依据；不记录检测器分数作为标签依据|

先固定完整输入的判定规则，再标注。安全分析中引用的攻击指令与真正要求模型执行的指令分开处理。所有模糊标签、目标改变与排除决定在看检测器输出前完成，保存数量、原因与裁决记录。

## 3. 数据集组成与构造方法

### 3.1 核心单元：目标组，而非孤立 prompt

对每个目标组 i，准备：

1. B_i：与 H_i 同领域、相似任务和输出形式的合法、经授权正常任务。
2. H_i：要求有害结果的原始执行请求。
3. W_m(B_i)：正常目标加入同类包装，作为对照，完整输入仍须审核。
4. J_im = W_m(H_i)：保持 H_i 目标的越狱尝试。

例如“真实授权付款提醒”与“用虚假身份或事实诱骗付款”可形成目标对。不要把“如何防范某攻击”机械当作所有有害执行任务的 B，否则差分可能主要反映执行/分析、语气或回答格式。

B/H 在主题、语言、任务类型、输出形式和长度上尽量匹配；避免正常端全有“合法”“安全”、有害端全有“非法”等标签捷径。长度比超出预先约定的宽松范围时标记人工复核，不能为了匹配长度破坏目标。对 W(H) 必须核验目标保持；无法找到精确原始 H 的材料不进入操纵配对构建，可作为标记清楚的外部诊断材料。

### 3.2 优先使用可追溯公开材料

|来源|可复用内容|本方案的使用规则|
|---|---|---|
|[AdvBench](https://github.com/llm-attacks/llm-attacks/blob/main/data/advbench/harmful_behaviors.csv)|原始有害 goal|target 是目标回答前缀，不是正常 prompt，不混入检测输入|
|[HarmBench](https://github.com/centerforaisafety/HarmBench)|原始行为、预计算攻击与必要上下文|保留 BehaviorID、上下文和攻击来源；不自动把全部样本视为本模型成功攻击|
|[JailbreakBench](https://github.com/JailbreakBench/jailbreakbench)|有害/正常行为与按目标记录的攻击 artifacts|通过原始目标映射 H→J；正常行为不按行号机械配对|
|[StrongREJECT](https://github.com/dsbowen/strong_reject)|有害问题与输出评估资源|补充原始目标；输出自动评分不替代输入标签审核|
|[WildJailbreak](https://huggingface.co/datasets/allenai/wildjailbreak)|四类材料、vanilla/adversarial/tactics 字段|适合补充和外部验证，但四类不天然构成同目标同包装四元组；先核查访问条件与去重|
|[BeaverTails](https://huggingface.co/datasets/PKU-Alignment/BeaverTails)|正常候选及安全讨论材料|其标签针对 QA 对；is_safe 不直接当 prompt 安全真值，必须重新审核输入|

公开集间有来源继承与目标重叠，不能将“换数据集名称”视为目标未见。先核实版本、许可/访问条件与目标映射，再进入本项目数据池；优先复用已发布攻击文本，缺格才补构造。保留原文件、行号、来源模型和原始成功标签，不能因来源成功标签而筛掉当前模型不成功的尝试。

### 3.3 攻击家族和包装谱系

优先核验现有 AutoDAN、DrAttack、GCG/nanoGCG、PAIR/TAP、SAA 五组。GCG/nanoGCG 合为一族，PAIR/TAP 合为一族。SAA 应追溯至实际 Simple Adaptive Attacks 方法与原始样本，不能仅凭历史标签或文件名认定独立家族；无法核实则归并、替换或明确未知，不为凑五族强行保留。

每条记录同时保存：数据源、算法方法、归并家族、模板/后缀谱系、生成模型、生成种子与预算。多策略组合另记 tactic_tags，不把它既当单独未知家族，又允许其相同包装进入训练。家族定义、相近方法的归并理由、外层留出清单在确认评估前固定。

W_m(B) 的构造分两类：

- 可迁移模板：只替换任务主体，尽量保持其余包装；审核是否仍是正常目标以及是否含真实越权。
- 目标相关优化攻击：不能假定对 H 优化的后缀对 B 同样有效。可以记录后缀重放对照，或用同策略生成的匹配包装，但必须用 wrapper_transport 区分；不把“同方法”说成“同一包装”。不可迁移的缺格保留缺失原因，不能伪装完整四元组。

主指标使用预先收集的合格尝试，不依据检测头分数或攻击成功挑样本。若采集本身有目标 LLM 查询，固定预算、记录全部尝试，并预先指定每个目标/家族的主样本抽取规则；多次攻击尝试属于同一目标的相关重复。

### 3.4 四类额外控制

每个目标组标准版再准备四条控制：

1. N(B)：正常目标的中性扩写。
2. N(H)：保留有害目标的中性扩写；它仍是有害输入，不是安全负例。
3. R(B)：普通角色或文风要求下的正常任务，不包含真实安全绕过。
4. Q(H)：引用或分析相关攻击的安全任务，明确不要求执行有害目标。

为控制规模，N(B)/N(H) 以预先分层分配的一种包装 m0(i) 为长度参考，五族尽量均衡；记录长度误差，不声称所有五族均逐条配齐中性长度对照。扩展版可补每族中性扩写。四条控制主要用于机制与误报诊断，默认不并入主概念、锚点或融合拟合；如考察困难负例增广，另立消融并重新拟合全流程。

## 4. 数量规划、标注与数据验收

### 4.1 三阶段规模

先导使用约 50 个已暴露开发目标，覆盖约 10 个目标/族的包装对照、各类安全材料与极长输入，验证标签准则、可迁移性、构造有效率、缓存和运行成本。先导目标永久归为开发材料，不再进入新确认。

标准版目标为 700 个新整理目标组，按 400 train / 100 select / 200 confirm 划分；下表按 K=5 个经核验家族、每格每族 1 条候选计算：

|角色|目标组|B/H|W(H)|W(B) 控制|四类额外控制|额外独立安全|候选合计|
|---|---:|---:|---:|---:|---:|---:|---:|
|train 目标组及关联控制|400|800|2000|2000|1600|1600|8000|
|select 目标组及关联控制|100|200|500|500|400|400|2000|
|confirm 新目标组及关联控制|200|400|1000|1000|800|2000|5200|
|calibrate 独立安全池|0|0|0|0|0|2000|2000|
|总计|700|1400|3500|3500|2800|6000|17200|

8400 条是四格核心候选；11200 条含额外四类控制；总库约 17200 条。表中 train/select 是目标组归属，不表示该行所有控制都参与拟合。每个五族外层留出折的主 train 实际使用：400H + 4×400J = 2000 正类，400B + 1600 独立安全 = 2000 负类；H/B 各计一次，不随包装数量重复加权。W(B) 和四类控制走独立诊断面板。完整五族已见设置的类比率另行如实记录。

这些是采集规划值，不是已完成数量，也不是已证明有足够功效的最小样本量。审核或可迁移性不足时，按预先规定的候补规则处理；缺失/失败率必须报告。主方法在共同可用文本上与基线比较；完整四格机制分析用审核合格的四格子集，不能因一格难构造而事后只保留对本方法有利的目标。若核心机制面板过小，补齐工作先于确认解盲。

资源紧张时可采用 200/80/120 个目标组及较小安全池，结论相应降为初步验证；不能为节省成本把同目标的多条包装计为更多独立目标。若主张稳定的 1% 低误报，安全测试池建议由 2000 扩至 5000，是否扩展须由先导精度需求决定并在确认前固定。

### 4.2 安全池构成

额外安全 train/select/calibrate/confirm 分别独立抽取，建议预定为 60% 普通请求、20% 敏感主题的合法分析、20% 普通角色/格式/长上下文请求；不包括外层留出家族的 W(B)。具体领域比例在采集时固定，所有方法共享同一文本池。

安全校准不使用任何攻击、原始有害、真实越权 W(B)、最终确认材料；其数量分辨率与实际测试 FPR 分开报告。独立安全测试池与确认四格 B/W(B) 分组报告；若汇总，按唯一记录去重并说明混合权重，不重复计数。

### 4.3 审核流程

1. 来源工具或 LLM 可提议标签和配对，保留其身份、版本和原始建议，但不直接升级为人工审核。
2. 每条拟进入主实验的记录至少一人审核；所有概念配对、W(B)、校准和确认输入优先双人独立复核；其余普通安全材料至少分层抽取 20% 做第二人检查。
3. 审核者不看检测器预测、分数和比较方法身份；冲突由第三人裁决，或保留 uncertain。
4. 保存原始分歧、一致率、各轴 Cohen κ/类别计数、裁决及排除理由。单人加模型复核只能报告为单人审核，不能称双人人工复核。
5. 先导阶段固定判断手册及质量门槛；出现高分歧先修规则并重标开发样本，不查看确认分数后改标签。

### 4.4 数据验收门槛

- 唯一 ID、原文哈希、来源、版本、配对端点和角色完整。
- 风险对、操纵对及四格映射语义可核查；不依赖行号猜配对。
- 规范化文本去重、近重复目标/改写审查及模板谱系审查完成。
- 标签不确定、目标改变、缺格、来源不明分别计数；主分析纳入规则固定。
- 各族、目标领域、语言和长度分布公开；族样本不均衡则报告宏平均与真实分母。
- confirm 未进入任何模型或超参数选择；不能仅设置 exposure 字符串就宣称独立。

## 5. 数据记录、文件布局和泄漏控制

建议原始新版材料另存于 data/v3_raw、data/v3_reviewed 和 data/v3_panels，保留现有 data/development 不动。路径为待建立方案；本次不创建数据或伪造标注。

每条原始记录至少包含：id、text、text_sha256、goal_cluster_id、paired_goal_id、original_id、condition(B/H/WB/WH/NB/NH/RB/QH)、source_dataset/version/record_id、attack_method、attack_family、template_lineage_id、tactic_tags、source_target_model、generation_metadata、language、domain、各主干完整模板 token 数、上述多轴标签、reviewer/adjudication、role、exposure。

配对表与文本表分开：risk_pairs(H,B)、manipulation_pairs(WH,H)、quadruples(B,H,WB,WH,method,transport)、controls(reference_id,control_id,control_type)。成功输出和 judge 另表保存，不能作为 prompt 文本的一部分输入检测器。字段是拟新增协议，不代表现有加载器已支持。

先按“目标的实质语义及其近重复改写”形成 goal_cluster，再分 train/select/confirm；同一组内 B/H 及全部包装、引用和派生控制随组移动。相同大领域不必合成一个目标，避免把所有“写邮件”任务合成一组。安全独立池也按实际近重复任务分组。

模板/家族留出是另外的轴：通用模板可能连接很多目标，不能机械对 goal×template 图取连通分量，导致全部目标成为一个组。模板未见声明则单独确保相应谱系不跨可见/评测侧。划分种子、候补顺序和清单先冻结，禁止根据模型结果移动样本。

所有外层折对留出家族 f 的 WH、WB、同谱系副本及其操纵配对执行禁入；即使 WB 的人工标签为安全，也不能作为该折锚点、标准化、选层控制、融合或校准的输入。仅删 kind=jailbreak 不足以防这种泄漏。

## 6. 两种泛化协议与独立确认

### P1：未见攻击家族，目标可见

对每个家族 f，用其余 K−1 家族拟合；对 train 中出现过原始 H 的目标，评测从拟合中排除的 f 包装。该协议只回答“新攻击形式能否绕过已学习目标风险”。不把训练过的 H 计为独立直接有害测试。相应家族的包装对照同样未参与拟合。

### P2：攻击家族和目标双留出，作为主要结果

train 使用 400 个目标及 K−1 家族；select 使用另外 100 个目标及 K−1 家族；confirm 使用一组全新的 200 个目标。五个外层头都在同一批 200 个目标上评测各自留出的家族包装，因此最多形成 5×200 条 W(H)，但独立目标数仍是 200，不是 1000。每个目标最多有五个相关的家族条件，统计时保留目标组内配对。confirm 组的 B/H、全部包装/改写/控制均不得进入训练、锚点、标准化、选层、融合、校准。直接有害 TPR 用这 200 个新的 H 计算。

五族形成五个独立拟合的检测头，每个头的内部验证只在剩余四族中做 leave-one-family-out，并重新构造对应概念与锚点；不得把 confirm 的 f 用于选层。P1/P2 可共享同一个冻结头，只改变评测目标面板，不需为两种测试重新拟合。

### P0：已见家族、未见目标，作为参考

用五族 train/select 拟合一个完整头，在新目标上评测同五族。它是已见策略泛化参考，不能混入 P2 宏平均以提高“未知类型”指标。

confirm 数据与所有方法、外层折、阈值、失败规则的清单冻结后统一解盲；不能看完一个族的确认结果再调整其他族。确认访问、模型包哈希和报告时间留档。若根据结果修改方法，原 confirm 从此成为开发材料，下一版本需新确认数据。

现有 diagnose 仍是已暴露开发诊断；既有 1665 条可用于工程验证和历史对照，不能换名字成为新确认。所谓独立是相对本研究的拟合/选择及开发过程，不声称基础 LLM 的预训练从未见过公开材料。

## 7. 主方法的拟合流程与冻结设置

### 7.1 表征提取

主实验 Qwen2.5-7B-Instruct，冻结官方 checkpoint 与 tokenizer/chat template，物理候选层 1–27，隐藏维 3584，含回答起始前缀的模板输入末个有效 token。FP16、batch1、固定依赖；不生成回答，不添加来源 target/completion。

先只用开发材料做资源预检并预定支持长度上限。数据收集时按所有主模型支持范围执行预先固定的可接收规则；超限完整保留为失败/范围外记录，不静默截断，不因确认表现删掉长请求。各模型须共享可评主面板；范围外压力测试另报。当前默认 2048 和历史实际 7500 不能混称同一协议。

每个模型对同一协议文本提取一次，缓存绑定模型 revision、模板、精度、位置、层号、文本与数据哈希。不同外层折/基线只读缓存，不从 confirm 拟合任何统计。按标准库 17200 条估算，单个 Qwen7B 的 FP16 末 token 缓存原始数值约 3.10 GiB，不含索引、其他池化或存储格式开销；实际耗时和显存由先导测量。

### 7.2 概念与锚点

每层只从该折 train 构造：

\[
D_l^T[i]=h_l(H_i)-h_l(B_i),\qquad
D_l^J[i,m]=h_l(W_m(H_i))-h_l(H_i).
\]

分别取未中心化差分矩阵第一右奇异向量，按训练差分均值统一符号。风险锚点是该折纳入主训练的正常输入均值；操纵锚点是有效操纵对中去重的 H 均值，不能每条包装重复计 H。查询读出：

\[
c_l^T(x)=\cos(h_l(x)-\mu_l^b,v_l^T),\qquad
c_l^J(x)=\cos(h_l(x)-\mu_l^h,v_l^J).
\]

W(B) 和诊断控制默认不参与方向、锚点、标准化或融合；在线不需要为新请求提供原始 H，不重新做 SVD。主算法维持秩 1，不预设两方向必须正交。

### 7.3 两概念分别选层

- 风险分支：H+可用 J 为正、正常为负。
- 操纵分支：J 为正、精确对应 H 为负；此 H 只是操纵对照，仍是最终风险正类。正常只作安全误报控制。
- 内部每折重建概念/锚点，最差内部折及正类组 AUROC ≥0.55 准入。
- 层的参考阈值只取内部训练参考：风险用正常，操纵用对应 H，参考预算 .05。操纵参考的“误报”不是安全输入 FPR。
- 默认效用：ΔTPR_worst + .25ΔTPR_mean − ΔFPR_safe,macro − .05×最大绝对响应相关。
- 每概念最少 2、最多 4 层；达到最少预算后仅加 U>0 的层。准入不足按失败报告，不降低门槛补结果。

选层覆盖并集只是贪心准则，不是最终 OR 判定器。AUROC 是准入及并列排序，不又加到效用中。

### 7.4 融合与校准

只用外层可用 train 重建最终概念，拼接选中标量并 train 标准化。拟合 s=w⊤z̃+b，以平均 BCE 加 λΣ_l||w_l||₂ 正则；同物理层 T/J 属同一组，默认 λ=.01，max_iter=10000、tol=1e−7，未收敛不冻结。

这是 V3 的计划校准规模，较当前实现的 140 条 calibrate 记录有所扩充；执行前须新增并验证相应数据角色/runner 与冻结产物，不得把当前 `METHOD.md` 默认配置误读为已使用 2000 条。计划中每个方法/模型/外层折独立对相同的 2000 条安全 calibrate 输入评分。分别按 α=.05（主要操作点）和 .01（次要操作点）确定 τ，使经验 FP 不超过 floor(nα)，同分保守处理，统一 s≥τ 为风险。两个操作点不需要重新训练 head，不在测试上插值阈值或挑 ROC 点。该预算不保证未来分布 FPR。

冻结包包括层集、方向、锚点、标准化、权重、阈值、配置、训练角色清单和提取哈希。主干继续完整前向，不声称选层带来提前退出。

## 10. 指标、统计与成功标准

主要终点：P2 在 α=.05 安全校准操作点下，五个留出家族 TPR 的等权宏平均。共同报告每族 TPR、最差族 TPR、独立安全测试的实际 FPR、全新 H 的 TPR；α=.01 为预定次要操作点。每个方法每个外层头独立校准；不能在确认 ROC 上选一个恰好5% FPR的点再称安全校准结果。

补充：AUROC、必要的 PR 曲线、各类安全对照 FPR、TP/FN/FP/TN 和分母、各域/长度分组、失败状态、训练及运行成本。准确率/F1/precision 受人工采样比例影响，不作为主要结果。直接 H 与多个 J 分开报，防止每目标五条 J 淹没 H。

统计独立单位是 goal_cluster_id。共享目标的各家族包装、种子、四格和控制保持成组；层数与重复包装不是样本量。方法差异使用相同目标的配对 cluster bootstrap（建议10000次，预先固定种子），保留每组全部条件。安全池按独立安全目标另行聚类。跨家族使用共同目标抽样，不能把5族×200=1000条攻击当作1000个独立语义目标。

主要比较预定 B0 vs B1；双概念价值同时比较 B0 vs B4、B0 vs B5，报告差值与95%区间。确认性显著性检验采用目标组配对差值，并对这两个单概念次要比较使用 Holm 校正；主要比较单独报告。不能事后取确认集上最佳单分支来包装成“预定最强单概念”。多随机种子 MLP 报各种子及均值/离散，不挑最好种子；确定性流程重跑同样输入不是独立重复。

200个独立目标若某族180/200检出，Wilson 95%区间约85.06%–93.43%；100/200时约43.14%–56.86%。2000独立安全请求若100误报，区间约4.13%–6.04%；若20误报，约0.65%–1.54%。这些仅说明点估计精度，不是成对改进的功效分析；多变体依赖时采用组统计。当前140校准安全条目不够精细支撑1%低误报结论。

先导阶段估计目标级方法差异方差、配对不一致率、有效构造率与人工成本，再一次性确定最终 N 与停止规则。若目标是可靠识别3–5个百分点的改进，200目标可能不足；不得看确认结果后追加至显著。固定模型的bootstrap只给条件不确定性；训练/校准稳定性另做预定的组重采样并重拟合，不混称同一置信区间。

支持“双概念有效”的最低证据组合：目标保持与包装混杂检查通过；P2 比较有实际增益且区间及误报代价可接受；直接H未明显漏检；收益不只来自更多层；跨至少另一主干设置可重复。若无增益或安全误报上升，报告失败边界，不用可视化替代主要指标。

## 11. 实验数量与计算安排

参考7B主要比较 B0–B5 × 5个P2外层家族 = 30个独立拟合/冻结的检测头。每个头可同时在P1/P2及两个α下评估，不把它们计成额外训练。P0另拟合；原版决策适配及其他消融单独计数。

先完成主比较和少量机制关键消融，再扩主干；不将所有主干×参数×随机种子×语言×攻击预算做全笛卡尔积。概念方法共享相同训练角色的合法概念缓存，变化配对时须重建；表征只在提取协议相同时共享。随机层/随机方向次数、MLP种子数、学习曲线子集在运行manifest中固定。

每轮保存 plan、输入哈希、checkpoint、stdout/stderr、退出码、模型、参数、校准与逐样本预测。准入不足、未收敛、超长/OOM和外部基线无法复现均作为结果状态报告，不调整门槛追逐成功。资源和耗时只用先导实测估算；本方案不启动云实例或延续旧运行。

## 13. 执行顺序与阶段门槛

1. 冻结研究范围、主任务、多轴标签、家族归并、P1/P2定义、主终点和操作点。
2. 完成约50个已暴露先导目标；核查来源映射、WB可迁移、审核分歧、标注/提取成本和极长输入。
3. 按目标/来源分组分配新材料，再派生包装与控制；确定最终样本量、替补/停止规则，不查看确认预测。
4. 完成标注、去重和角色审计；归档排除和构造失败。新确认与旧diagnose严格分开。
5. 补齐数据适配、外部基线、完整单分支、预算与统计工具；只在开发材料做实现验证。
6. 固定主实验配置、baseline实现合同、种子、所有实验行和资源上限，生成manifest。
7. 固定主干提取协议，提取缓存；拟合所有外层头及预定消融，安全校准后写冻结包，保留失败项。
8. 所有冻结包验收后统一评估确认材料，生成逐样本、分组与成对差异结果；不回流拟合。
9. 做预定机制图与成本测量；拓展实验用独立面板。若方法改变，另建新确认版本。
10. 撰写结果：同时呈现收益、误报、置信区间、失败家族和未覆盖威胁模型。

阶段顺序由产物决定，不预报未经实测的GPU小时或“几天必完成”。可并行的是来源审计、标注准备和基线实现；确认评估依赖前述冻结门槛，不能提前。
